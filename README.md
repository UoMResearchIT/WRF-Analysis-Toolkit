# WRF Analysis Toolkit

This is a mono-repo that contains:

- `wrf_analysis_toolkit`: a set of scripts to generate diagnostics from WRF outputs, and to compare them with other WRF outputs.
- `wrf_widget`: a  widget for visualizing WRF model output data.
- `rip_toolkit`: a set of functions to generate trajectories from WRF outputs using RIP.
